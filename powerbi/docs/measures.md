# Measures

Generated by `tools/spec.py`. Grouped by display folder.

## Run Count

*Runs* · table `Runs` · format `#,0` · Pipeline runs recorded.

```dax
Run Count =
COUNTROWS ( Runs )
```

## Latest Status

*Runs* · table `Runs` · format `General` · Status of the latest run.

```dax
Latest Status =
VAR _last = CALCULATE ( MAX ( Runs[Run Number] ), REMOVEFILTERS ( Runs ) )
RETURN UPPER ( CALCULATE ( MAX ( Runs[status] ), REMOVEFILTERS ( Runs ), Runs[Run Number] = _last ) )
```
