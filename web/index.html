05 · How it's wired

From a Google Form to a live dashboard

ExportA drive's Google Form responses are exported and dropped into incoming/. A new drive is one line in config.yml.
TriggerThe push, a weekly schedule or a manual click starts the GitHub Action.
Testpytest runs first. A broken stage never touches the data.
Run & gateIngest → anonymise → clean → model → validate. A failed error-level check stops the publish.
PublishTables and the run manifest are committed. Dashboards read them straight from GitHub on the next page load.
The data shown here is synthetic: generated by samples/generate.py to mimic the real exports' structure and mess, with no real people in it. The same pipeline runs on the real One Health Lifesavers exports privately, using a secret key for donor IDs. Built by Qais Adeniji-Bello.
